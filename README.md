# Newecommerce

Ядро интернет-магазина на основе ООП. Проект описывает основные
сущности e-commerce — товары и категории — и умеет загружать их
из JSON-файла.

## Структура

- `src/product.py` — класс `Product` (название, описание, цена, количество).
- `src/category.py` — класс `Category` (название, описание, список товаров).
  Содержит атрибуты класса `category_count` и `product_count`,
  которые автоматически считают количество категорий и товаров.
- `src/utils.py` — функция `load_data` для загрузки
